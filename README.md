## 📁 Folder Structure

- `/project-files/frontend`: React frontend
- `/project-files/backend`: Node.js + Express backend
- `/Document`: Project report or documentation
- `/Video Demo`: Final recorded demo video

## 🛠️ Tech Stack

- **Frontend:** React, Tailwind CSS
- **Backend:** Node.js, Express
- **Database:** MongoDB
